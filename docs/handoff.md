# 引き継ぎ資料：家電・家具 比較アカウント「どっち買い」

作成日：2026-10-29
元の設計書（全文・出典リンクつき）：https://claude.ai/artifact/Xsk5FdpftK3q8qGDDRRmPb

## 1. プロジェクト概要

- 目的：SNSで集客し、noteの記事でアフィリエイト収益を得る
- ジャンル：家電・家具
- 発信内容：人気ランキング、A vs B 比較、条件別の選び方（「こうならこっち」）
- 運用者：Koyo（個人）

## 2. ブランド

| 項目 | 内容 |
| --- | --- |
| ブランド名（推奨案） | どっち買い｜家電と家具の結論 |
| 代替案 | 迷わん家電 / くらし選び研究所 |
| タグライン | 迷ったら、あなたの条件で“こっち”を決めます。 |
| ポジション | 「おすすめ10選」ではなく、読者の条件を聞いて1つに決める（条件→結論） |
| ターゲット | 25〜40歳。引っ越し・新居・買い替えで、候補を2〜3個に絞ったが決めきれない人 |
| 発信者像 | 新居を一式揃えた会社員の「比較係」。専門家ぶらず、言い切る |

### 口調ルール

- する：条件つきで言い切る（「〇〇ならA一択」）／違いは数字で書く／デメリットを1つは書く／です・ます調の短文
- しない：「どれも良い」で終わる／「神家電」「買わなきゃ損」などの煽り／最安値・在庫の断定／説明なしの専門用語
- 使った物は「使用レビュー」、調べただけの物は「スペック比較」と分けて表示する

### ビジュアル

- 白ベース＋アクセント1色（例：深緑）。A＝グレー、B＝アクセント色で固定
- 1枚目は毎回「AとB、どっち買い？」＋商品写真2つ
- 最後は毎回「こんな人はA／こんな人はB」の結論カード
- 1枚目に大きな文字で「誰の・何の悩みか」を入れる（ニトリ型の文字入れ）

## 3. 収益導線

Threads（毎日・短文で反応テスト）→ Instagram（週3本・カルーセル）→ プロフィールのリンク → noteマガジン「どっち買い図鑑」（無料の比較記事）→ Amazon・楽天で購入

- SNSは「答えが分かる場所」、noteは「機種名とリンクを渡す場所」
- フォロワー1,000人超で有料note「新居まるごと選び方ガイド」を検討
- Xは後回し

### 見る数字

| 場所 | 指標 | 目的 |
| --- | --- | --- |
| SNS | インプレッション、保存数、返信数、プロフィールのリンククリック | 集客。どのネタが広がるか |
| note | ビュー、アフィリエイトリンクのクリック、成約数 | 収益。どの記事が売れるか |

最初の目標は再生数ではなくリンククリック数（閲覧数と成果は比例しない例が多い）。

## 4. 買う前の6つの壁（全コンテンツで必ず答える）

1. サイズ：本体寸法＋置くのに必要なスペース（扉の開き、壁との隙間、搬入経路）と「測る場所」
2. 機能の違い：価格差の理由になっている機能を3つまで。他は「どれも同じ」と書く
3. その機能のあり／なしで生活がどう変わるか（1文で）
4. なくても良い人は誰か（言い切る）
5. 安さだけで選ぶ危険：安全（リコール）・ランニングコスト・保証/修理・消耗品
6. ネットで買うか店で見るか：小型家電・型番が決まっている物はネット。座る・寝る家具と設置が必要な大型家電は「店で確認してネットで比較」

サイズの失敗例：洗濯機の防水パン内寸・排水口位置、ドラム式の扉スペース、冷蔵庫の搬入経路、ロボット掃除機が入る家具下の隙間、ソファ前の動線。

ネット購入の注意：マーケットプレイスの販売元確認、大型家電は設置・引き取りが別料金/別申込のことが多い（エアコン・テレビ・冷蔵庫・洗濯機は家電リサイクル法の対象）、大型品は返品が大変。

## 5. コンテンツの型（この3つだけで回す）

### ① A vs B 比較（最も売れる）
1. 結論：「〇〇ならA、△△ならB」
2. サイズと必要スペース（測る場所つき）
3. 違いは3つだけ（数字で）
4. その機能があると何が変わるか、なくても良い人
5. 安さだけで選ぶと危ない点
6. ネットか店か
7. 結論カード

### ② 条件分岐チャート（保存・フォロワー増）
質問は3つまで、YES/NOで1つの商品タイプに着地。最後に「詳しい機種はnoteで」。

### ③ 条件別ランキング（noteで強い）
総合ランキングは作らない。必ず条件をつける（例：6畳に置けるソファ TOP3）。順位の基準を冒頭に明記し、各順位に「理由」と「合わない人」をセットで書く。

## 6. SNSテンプレート

### Instagramカルーセル（8枚）
1. 表紙「AとB、どっち買い？」 2. 結論 3〜5. 違い①〜③ 6. 後悔ポイント 7. 結論カード 8. noteへの送客＋保存のお願い

### Threads
3行以内の短文。最後に問いかけ（「Aならコメント、Bならリポスト」）。コメントには必ず返信。

```
ドラム式と縦型、迷ってる人へ。

・乾燥まで毎日 → ドラム式
・泥汚れが多い → 縦型
・置き場所が狭い → 縦型

あなたならどっち？
```

### プロフィール
- 名前：どっち買い｜家電と家具の結論
- 1行目：迷ったら、あなたの条件で“こっち”を決めます
- 2行目：違いは3つ・結論は1つ／新居を一式揃えた比較係
- リンク：noteマガジンへ直接

## 7. note比較記事の構成

1. 冒頭にPR表記
2. 結論＋商品リンク
3. 比較表（5項目まで）
4. 違い3つの解説
5. こんな人はA／B（2回目のリンク）
6. よくある迷い Q&A 3つ
7. 関連記事

リンクは「詳しくはこちら」ではなく「乾燥まで毎日回すならこのモデル」のように条件と一緒に置く。

## 8. リサーチ要点（2026年10月下旬時点）

## 11. 守るべきルール

- アフィリエイトリンクを含む投稿・記事は冒頭にPR表記（例：「※本記事はアフィリエイト広告（PR）を含みます」）。2023年10月からステマ規制（景品表示法）の対象
- Amazonアソシエイトはnoteページの審査通過が条件。審査待ちの間は楽天アフィリエイトを使う
- 価格は「〇万円台（記事執筆時点）」と幅で書く。「最安」「今だけ」は書かない
- 使っていない物を「使った」と書かない
- 紹介商品は公開前に消費者庁リコール情報サイト（https://www.recall.caa.go.jp/）で品名を検索する
- 価格・ランキング・規約は変わるので、記事作成時に必ず最新情報を確認する

## 12. 30日ロードマップ

- 1週目：アカウント名・プロフィール・アイコン決定／Amazonアソシエイト・楽天アフィリエイト申込／Canvaでカルーセルの型を作る
- 2週目：Threadsで毎日1本、ネタ帳から結論だけ投稿して反応を見る
- 3週目：反応上位3ネタをInstagramカルーセル化／同テーマでnote比較記事3本
- 4週目：条件別ランキング記事2本／noteマガジン作成／プロフィールのリンクをマガジンに
