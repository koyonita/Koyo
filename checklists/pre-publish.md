# 公開前チェックリスト

まず自動チェックを通す：

```bash
python3 scripts/check_article.py articles/drafts/<ファイル名>.md
```

自動チェックが見ているもの：PR表記の位置／禁止ワード／価格の「記事執筆時点」表記／`【要確認】`の残り／
front matterの確認日／「使用レビュー」「スペック比較」の表記／6つの壁の見出し／比較表の項目数／
「詳しくはこちら」型のリンク文言。

## 手で確認すること

### 事実
- [ ] 価格・型番・仕様を公式サイトか販売ページで確認した（確認日を `prices_checked` に記入）
- [ ] 全商品を消費者庁リコール情報サイト（https://www.recall.caa.go.jp/）で検索した（`recall_checked` に記入）
- [ ] ランキングの順位の根拠を説明できる
- [ ] 「使用レビュー」と書いた物は本当に使っている（`content/ideas.md` の使用リストにある）

### 6つの壁
- [ ] サイズ：本体寸法＋必要スペース＋「測る場所」を書いた
- [ ] 機能の違い：3つまで。他は「どれも同じ」と書いた
- [ ] その機能のあり／なしで生活がどう変わるか1文で書いた
- [ ] なくても良い人を言い切った
- [ ] 安さだけで選ぶ危険（安全・ランニングコスト・保証・消耗品）を書いた
- [ ] ネットか店かを書いた。大型家電は設置・引き取り料金、家電リサイクル法対象品（エアコン・テレビ・冷蔵庫・洗濯機）に触れた

### 口調
- [ ] 結論が条件つきで言い切れている
- [ ] デメリットを1つ以上書いた
- [ ] 専門用語に一言説明がある

### リンク
- [ ] アフィリエイトリンクは実際に開いて正しい商品に飛ぶ
- [ ] マーケットプレイスの場合、販売元を確認した
- [ ] Amazonアソシエイト審査中なら楽天のリンクを使っている

### SNS
- [ ] カルーセル1枚目に「誰の・何の悩みか」が大きく入っている
- [ ] 最後に結論カード（こんな人はA／B）がある
- [ ] PR商品を含む投稿はキャプション冒頭に「PR」がある
