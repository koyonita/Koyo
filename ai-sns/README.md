# AI発信アカウント 運用フォルダ

設計は `branding.md` を正とする。

## 役割分担

| 担当 | やること |
| --- | --- |
| Claude | 毎朝のリサーチ、ネタ出し、投稿の下書き（X / Threads）、出典の記録 |
| 本人 | 下書きの確認と修正、投稿、**実録ネタの数字の記入**（実際にやった人しか書けない部分） |

依頼するとき：「このネタで書いて」と一言＋分かっていればメモ（何をやった／何分かかった）。

## フォルダ

- `neta/YYYY-MM-DD.md` … その日のネタと投稿の下書き（毎朝作成）
- `templates/post.md` … 投稿の型
- `branding.md` … ブランド・ターゲット・時事ネタの扱い

## 下書きのルール

1. 速報はしない。時事は「で、中小企業の業務で何が変わる？」まで落とす
2. 数字を入れる。根拠のない数字は書かず `【要確認】`
3. 本人が実際にやっていないことを「やった」と書かない。実録の数字は `【要記入】` にして本人が埋める
4. 書かない言葉：「ヤバい」「〇〇は終わった」「知らないと損」「AIで月〇万」「神ツール」
5. 出典はファイル末尾に残す（投稿本文には入れなくてよい）
6. ニュースの日付・名前が情報源で食い違うときは、公式発表を確認するまで `【要確認】`
